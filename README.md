# HVAT

Калькулятор пружин и локальный журнал тренировок. Данные тренировок хранятся в IndexedDB на устройстве. Для переноса или резервной копии откройте «Тренировки → Мои данные → Экспорт», затем используйте «Импорт» на другом устройстве. Импорт добавляет записи без дублирования; при совпадении ID локальная запись сохраняется.

## Офлайн режим и обновление

После первого открытия с сетью service worker сохраняет файлы приложения, и установленная версия может запускаться без интернета. Каждое изменение файлов офлайн оболочки требует увеличения `CACHE_NAME` в `service-worker.js` (`hvat-static-v11` сейчас). Для обновления откройте приложение с интернетом, закройте остальные вкладки HVAT и перезапустите приложение. Если старая версия остаётся, очистите данные сайта `haevrogh.github.io` в браузере или переустановите PWA. **Сначала экспортируйте новые записи:** очистка данных сайта или удаление установленного приложения может удалить локальные тренировки.

Обновление тренировочной базы с версии 1 или 2 до версии 3 намеренно однократно удаляет прежние программы, журнал, ручные ПМ, шаблоны и незавершённые занятия. Настройка звука сохраняется. Новые записи при следующих открытиях остаются. Для штатного обновления очищать данные сайта не нужно. Старые резервные копии версий 1–2 несовместимы и не импортируются; новая версия использует копии формата 3.

Звуковой отсчёт и вибрация работают по возможностям браузера при открытом приложении. При блокировке экрана своевременный сигнал не гарантируется.

## Тренировки и рекорды

Введите фактическое количество повторений и нажмите «Подход выполнен». Опросов техники, боли и запаса повторений нет. После подхода открывается полноэкранный таймер отдыха. Кнопки ±30 секунд меняют только текущий отдых; его можно свернуть, развернуть или пропустить. Остаток времени восстанавливается после перезагрузки.

Ручные рекорды: «Тренировки → Внести ПМ», рука, 1–10 повторений, сочетание пружин и дата. Автоматические рекорды учитывают фактически выполненные 1–999 повторений, включая дополнительные повторы на пределе оборудования. Рекорд относится к указанному числу повторений, без пересчёта в другие ПМ. Формат экспорта и импорта — 3.

Шрифты Manrope и Sora распространяются по лицензии SIL OFL; тексты лицензий — `fonts/OFL-Manrope.txt` и `fonts/OFL-Sora.txt`.

## Прогрессия

Программа последовательно проходит четыре периода: выносливость, сила, быстрота и пик силы. Выбери дату пика и длительность 4–52 недели, укажи и подтверди отдельный исходный 1ПМ обеих рук. Начало рассчитывается назад от выбранной даты. В каждой неделе три занятия; заключительная проверка результата входит в расписание.

Весь план виден перед запуском и сохраняется целиком. Расчётная база растёт на 1% в неделю; пропуски и недоборы не меняют даты или будущие нагрузки. Это плановый ориентир, фактические рекорды появляются только после выполнения. Выше максимальных 120,4 кг программа сохраняет число подходов и добавляет повторения для приближения планового объёма. Конфликтующие программы при импорте сохраняются локально либо копируются целиком. Правила, источники и проверки — в [описании прогрессии](design/progression.md).
