# HVAT

Калькулятор пружин и локальный журнал тренировок. Данные тренировок хранятся в IndexedDB на устройстве. Для переноса или резервной копии откройте «Тренировки → Мои данные → Экспорт», затем используйте «Импорт» на другом устройстве. Импорт добавляет записи без дублирования; при совпадении ID локальная запись сохраняется.

## Офлайн режим и обновление

После первого открытия с сетью service worker сохраняет файлы приложения, и установленная версия может запускаться без интернета. Каждое изменение файлов офлайн оболочки требует увеличения `CACHE_NAME` в `service-worker.js` (`hvat-static-v9` сейчас). Для принудительного обновления откройте приложение с сетью и перезапустите его. Если старая версия остаётся, очистите данные сайта `haevrogh.github.io` в браузере или переустановите PWA. **Сначала экспортируйте историю:** очистка данных сайта или удаление установленного приложения может удалить локальные тренировки.

Звуковой отсчёт и вибрация работают по возможностям браузера при открытом приложении. При блокировке экрана своевременный сигнал не гарантируется.

Шрифты Manrope и Sora распространяются по лицензии SIL OFL; тексты лицензий — `fonts/OFL-Manrope.txt` и `fonts/OFL-Sora.txt`.

## Прогрессия

Новая вкладка объединяет независимые программы правой и левой руки в одно занятие. Доступны волны, double progression и тест максимума с прибавкой повторений. Настрой методику каждой руки, проверь первые занятия и запусти программу. Повышения подтверждаются отдельно; даты не повышают нагрузку автоматически.

База автоматически обновляется до версии 2 с сохранением истории. Очистка данных для обновления не нужна. Экспорт версии 2 включает программы и связанные занятия; импорт версии 1 поддерживается. При конфликте выбирай локальную программу целиком либо отдельную копию. Детали и проверки — в [описании прогрессии](design/progression.md).
