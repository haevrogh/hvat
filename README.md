# HVAT

Калькулятор пружин и локальный журнал тренировок. Данные тренировок хранятся в IndexedDB на устройстве. Для переноса или резервной копии откройте «Тренировки → Мои данные → Экспорт», затем используйте «Импорт» на другом устройстве. Импорт добавляет записи без дублирования; при совпадении ID локальная запись сохраняется.

## Офлайн режим и обновление

После первого открытия с сетью service worker сохраняет файлы приложения, и установленная версия может запускаться без интернета. Каждое изменение файлов офлайн оболочки требует увеличения `CACHE_NAME` в `service-worker.js` (`hvat-static-v7` сейчас). Для принудительного обновления откройте приложение с сетью и перезапустите его. Если старая версия остаётся, очистите данные сайта `haevrogh.github.io` в браузере или переустановите PWA. **Сначала экспортируйте историю:** очистка данных сайта или удаление установленного приложения может удалить локальные тренировки.

Звуковой отсчёт и вибрация работают по возможностям браузера при открытом приложении. При блокировке экрана своевременный сигнал не гарантируется.

Шрифты Manrope и Sora распространяются по лицензии SIL OFL; тексты лицензий — `fonts/OFL-Manrope.txt` и `fonts/OFL-Sora.txt`.
